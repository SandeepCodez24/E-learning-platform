this fullstack components library contains reusable frontend+backend feature bundles, one per folder under `components/`.

## Components

1. **`components/login-signup-mysql-otp/`** — username/password auth with email OTP verification (signup + forgot-password), JWT sessions, MySQL storage. Flask backend + React (Vite) frontend.
2. **`components/elearning-auth/`** — Login/Register screens for an e-learning platform, built from the "E Learning Site (Community)" Figma design. JWT auth, hashed passwords (Werkzeug), SQLite storage. Flask backend + React (Vite) frontend. See `components/elearning-auth/README.md` for setup.
